# USJ待ち時間ナビ

USJの公開データをもとに、アトラクションの待ち時間、20分ごとの履歴、過去の日別・時間帯別の混雑傾向、営業時間、ショーの開始時刻を表示する個人運営の非公式サイトです。USJ付近の天気予報と、身長制限・チャイルドスイッチによる絞り込みも表示します。

公開URL: https://uniba-waittimes.com/

## 構成

- Cloudflare Workers: 表示と定期取得
- Cloudflare D1: 20分単位の待ち時間履歴と営業時間
- GitHub: ソース管理

2026年10月6日に用いたCloudflare KVへの臨時退避は、D1の復旧と保留データがないことを確認したうえで2026年10月7日に停止しました。現在の20分記録はD1のみに保存します。D1が利用できない間の記録は欠測となり、復旧後に自動補完はしません。

待ち時間について、閲覧者の操作は保存済みデータの表示に限り、外部データ提供元への取得やD1への保存は定期ジョブが行います。公表開園時刻の2時間前または8時の早い方から閉園時刻の30分後まで5分ごとに取得し、履歴はこの時間帯の毎時0・20・40分の枠に数分後の取得値を保存します。実際の開園が早まる日に備えた取得開始時刻ですが、開園を保証するものではありません。取得失敗時は欠測として扱います。トップに当日の公表営業時間と現在の待ち時間上位5件を表示します。Xで上位情報を共有するときは月日・時刻と5施設の待ち時間を載せ、長い施設名のみ短縮表記にします。

D1の読み書きを抑えるため、20分ごとの記録と同じトランザクションで「今日の表示用履歴」も1件更新します。初回や不整合時は元の記録から再構築し、翌日は新しい日の記録へ切り替えます。営業時間は取得元に変更があった日だけ更新し、同じ内容の取得状態は書き直しません。画面の更新間隔と履歴の保存間隔は変えていません。5分前比には直前の取得結果1回分だけを別の管理値として上書き保持し、20分ごとの過去履歴は引き続き蓄積します。5分ごとの全記録を過去履歴へ追加する方式ではありません。HTMLは60秒、主要APIは内容に応じて短時間キャッシュします。キャッシュは永続保存先ではなく、記録の正本はD1です。

ページは「今日のパーク」（`/`）、「地図で探す」（`/map`）、「行く前に」（`/plan`）に分けています。今日のパークでは現在の待ち時間、今日のショー、休止情報、天気を表示します。地図で探すの標準表示はMapLibre GL JSとOpenFreeMapの地理地図です。ThemeParks.wikiの施設座標を1日1回（失敗時は15時に再試行）取得し、D1の `app_meta.map_locations_payload` に保存します。初回・障害時は `public/map-locations.json` のビルド時スナップショットを使用します。生JSONはGit管理から除外し、未生成時のビルドでは `scripts/sync-map-locations.mjs` がAPIから作成します。このJSONの直リンクは404にして、地図ページ内で描画に使います。アトラクション23地点と飲食店48件を表示でき、飲食店は初期状態で非表示です。施設の座標は入口や歩行ルートの保証ではありません。閲覧者が明示的にボタンを押して許可した場合だけブラウザーのGPS現在地を地図上に示し、サイトのサーバーには送信しません。既存の `/api/waits` と `/api/today` を読み、ピンに現在の待ち時間と20分前比の矢印を表示します。差が5分未満なら「→」、比較できない場合は矢印を出しません。イラスト地図は切り替え可能な予備表示として残します。画像上の座標は `public/map.html` の `spots` にあり、2026-10-08の運営者修正値を維持します。行く前にでは1つのカレンダーに過去の混雑実績と今日以降の営業時間・休止予定を表示し、ショーの日付選択とイベント情報も用意しています。各ページのタブから切り替えられ、ページごとに必要なAPIだけを読み込みます。「待ち時間の履歴と比較」の旧セクションは両ページで非表示とし、履歴APIの取得と、その画面専用だった過去7日同時間帯の比較計算も止めています。

スマホでは現在の待ち時間を最初の画面に置き、ページ内メニューから各項目へ移動できます。絞り込み・並び順・凡例はスマホ・PCともに初期状態で折りたたみ、天気の詳細と風速の注意目安も折りたたみです。カードとヒートマップには、5分前比と20分前比を並べて表示します。5分前比は連続する取得結果を比較し、取得間隔が3〜8分を外れた場合は比較しません。20分前比は、現在の取得時刻から20分前に最も近い当日の20分保存記録を使い、ずれが11分を超える場合は比較しません。どちらも5分未満の差は横ばいとし、比較できない場合は「—」とします。新しい履歴の保存やD1への追加読み取りは行わず、既存の当日履歴を利用します。スマホのヒートマップには今日の直近約6時間の20分枠と現在値を示すミニ棒グラフも表示します。棒グラフは最大18本で右端の濃い棒が現在値、欠測・休止中は底の薄い印です。各カードには「グラフ・履歴を見る ▼」を表示し、押すと当日の20分枠と現在値の棒グラフと直近6件の記録が開きます。スマホ・PCともに常時表示の「カード」「ヒートマップ」ボタンで切り替えられ、選択は端末のブラウザーに保存します。カードの棒グラフは縦軸の上限を30分単位で切り上げ（最低60分）、欠測・休止中は底の薄い印で示します。自動更新後も開いていたカードを維持します。PCの表は20分枠の時刻を見出しに表示し、実際の取得時刻は各セルの説明に残します。過去のカレンダーと実績の間にある凡例・注記、選択日の記録時刻・パス料金・天気実績は折りたたみです。

アトラクション名の下には、エリア名と🧒キッズ向け・👶小さなお子さまと一緒・🎢スリル・💧水濡れの特徴記号を表示します。今日のカード・ヒートマップ、過去の表・アトラクション別グラフが対象です。4つの特徴はAND条件で絞り込めます。分類は運営者がまとめた固定値で、利用条件を保証するものではありません。記号の説明は両ページで折りたたみ、詳しい利用条件はUSJ公式をご確認ください。

ジュラシック・パークとジョーズの通常版・夜間版は、それぞれThemeParks.wikiの別IDで現在値を確認します。ジョーズ ～レッド・アラート～はUSJ公式案内で2026年10月9日まで18:30から、10月10日以降は18:00から閉園までとされています。取得元で確認できない値はQueue-Timesの通常版の値で補わず、過去に保存した出典不明確なジョーズ2件のQueue-Times値は比較・集計に使いません。

天気は気象庁の大阪府予報と大阪観測所のアメダス実測値を表示し、USJ付近の時間別予報にはMET NorwayのLocationforecast APIを併用します。予報の詳細は折りたたみ表示とし、運行変更への注意文は常に表示します。気象庁データは10分、MET Norwayデータは提供元の `Expires` までD1にキャッシュします。MET Norwayの期限後は `If-Modified-Since` を使って再確認します。今後約6時間に平均風速7m/s以上または1時間降水量1mm以上の予報があれば注意、平均風速10m/s以上なら強い注意を表示します。最大瞬間風速が提供される場合は10m/s以上も強い注意の対象ですが、USJ付近のMET Norway予報には現在含まれないため、突風の自動判定はできません。数値は当サイトの目安であり、USJの運休基準や運休予測ではありません。お気に入りIDは閲覧者のブラウザーのローカルストレージにのみ保存します。

ショー開始時刻は開園前にも当日データが揃うまで5分間隔で確認します。今日のパークでは今日の時刻だけを表示します。行く前にでは今日から7日間を選択でき、初期日は今日です。スマホではショーごとに次の開始時刻と後続回を並べ、時間軸表示へ切り替えられます。選んだ表示は端末のブラウザーに保存します。時間軸は初回表示時に現在時刻の約20分前が左端に来るよう横スクロールし、データ更新では閲覧者の横位置を戻しません。将来日の時刻データが利用可能になった場合は、その日の最初のショーの約20分前から表示します。現在利用しているThemeParks.wikiのライブデータは当日分のみのため、先の日付は日付を指定したUSJ公式の日別スケジュールへ案内します。公式サイトは将来日の開始時刻を掲載していますが、公式APIの取得・再掲載は許諾確認が必要なため、本番の自動収集は無効にしています。許諾を得た正規データ提供を利用できる場合の表示処理は用意しています。

OGP画像、ブラウザーとホーム画面用のアイコン、Webアプリのマニフェストは `public/` に置いています。共有カードには運営者撮影の `og-photo.jpg` を元に「非公式サイト」を表示した `og-photo-labeled.jpg` を使用します。施設別の共有URLは `/r/<施設ID>` で、画面内の対象施設へ移動します。旧 workers.dev URL は独自ドメインへ転送します。API経由の単一ファイル配信では、`build.mjs` が画像をbase64で埋め込み、通常のWrangler配信ではCloudflareの静的アセットとして配信します。

「行く前に」のカレンダーでは、過去の記録日を選ぶと混雑の目安と時間帯・アトラクション別の平均、今日以降を選ぶと公表営業時間と休止予定を確認できます。混雑実績は2026年10月5日から記録しています。アトラクションごとの1日の推移はスマホでは棒グラフ、PCではグラフと表を切り替えて表示します。混雑の色分けは当サイト独自の暫定目安で、記録が18件未満の日は色を付けず「一部のみ」と表示します。平均は保存された営業中の待ち時間から計算し、記録のない時間帯は空欄として扱い、欠測を0分には換算しません。公開APIは集計値のみを返します。

年間パス（スタンダード）の入場除外日は、運営者が手作業で確認・転記した `public/pass-exclusions.json` を `/plan` のカレンダーに表示します。`checked_at` に確認日を記録し、画面に公式ページへのリンクを添えます。掲載月の空文字は「除外日なし」、月のキーがない場合は「未発表または当サイト未反映」として扱います。サイトとWorkerはUSJ公式ページへ自動アクセスしません。更新時は運営者が日付を再確認してJSONと確認日を手動修正し、ビルド・公開します。USJ公式の利用条件と再掲載の扱いは引き続き確認が必要です。

1デイ・スタジオ・パスの大人日別税込価格は `public/ticket-prices.json` へ手動登録しています。2026年10月5日・6日は利用者が10月7日と同額と申告した価格、10月7日以降は同日に確認したUSJ公式購入画面からの転記です。画面の最安表示から大人料金と判定したデータです。`/plan` の過去・今日以降のカレンダーと選択日の詳細に確認日付きで表示し、未掲載日は価格未確認として扱います。子ども・シニアの日別価格は掲載しません。最新価格と購入可否は公式の価格カレンダー・購入画面で確認してください。サイトから公式への自動取得は行いません。

カレンダーの祝日・振替休日・国民の休日は、内閣府の「国民の祝日」CSVを週1回取得してD1へ保存します。取得できない場合は holidays-jp の日付JSONを予備として使います。`/api/holidays` は祝日名・種類・取得元を返します。閲覧者の操作で提供元へ取りに行くことはありません。

気象庁アメダス大阪観測所の10分値を、前日分から直近8日を対象として日ごとにD1へ保存します。記録開始日は2026年10月5日で、それ以前の日は補完しません。最高・最低気温、1日と8〜22時の降水量、日照時間、取得率を記録し、カレンダーと選択日の詳細に表示します。雨・晴れ・くもりは観測値から当サイト独自に判定し、取得率が90%未満なら天気を不明と表示します。保存ジョブは営業時間外を含め15分以上の間隔で未保存日を1日ずつ処理します。カレンダーには待ち時間の保存がある日だけ表示し、天気だけの記録日は一覧に含めません。

## 英語版の試作

`/en/` に英語の試作ページを用意しています。日本語版と同じWorker内で `/api/waits`、`/api/today`、`/api/archive/*`、`/api/shows`、`/api/schedule`、`/api/weather` を読み、英語版専用のD1テーブルや収集Cronは設けません。現在値、20分履歴、日別・時間帯別の過去実績、ショー開始時刻、営業時間、天気を先に英語化しました。地図、プライバシーポリシー、イベント等の一部固有名詞は日本語版への導線や原文表記が残る試作段階です。

試作中の英語版は通常の `npm run build` には含めず、本番 `/en` は404です。ローカルで単一Workerを試す場合だけ `INCLUDE_EN=1` でビルドします。`wrangler.jsonc` の静的アセットを直接配備すると英語版のファイルも配信されるため、公開判断まで行わないでください。独自ドメイン取得と英語表記の確認後、公開するページだけ正規URLと `hreflang` を設定します。表示用のAPIは既存のキャッシュを共用します。天気APIは既存の期限切れ時にD1のキャッシュ値を更新する場合がありますが、英語版専用の保存処理はありません。

## 開発

Node.jsを使います。

```sh
npm ci
npx wrangler d1 execute usj-wait-nav-db --local --file migrations/0001_initial.sql
npx wrangler d1 execute usj-wait-nav-db --local --file migrations/0002_weather_days.sql
npx wrangler d1 execute usj-wait-nav-db --local --file migrations/0003_holidays.sql
npm run dev
```

Cloudflareアカウントで実行する場合は `wrangler.jsonc` のD1データベースIDを自分のものに変更してください。`npm run build` は単一ファイルのWorkerを `dist/worker.js` に生成します。

## 待ち時間の直近の動き（2026-10-09）

取得値が15分より古い場合は増減を比較しません。施設別カードには5分前比・20分前比・1時間前比を短く並べます。長い「直近の動き」文章ラベルは2026-10-09に利用者の指摘を受けて削除しました。20分前比と1時間前比は、既存の当日20分記録から対象時刻に最も近い記録を選び、ずれが11分を超える場合は比較しません。差が5分未満なら横ばい、休止・欠測・推定値や取得元の相違などで比較できない場合は「—」です。上部には比較可能な全施設の5分・20分前比の増加／横ばい／減少件数を示します。LINE・X共有文も長い傾向文を外し、施設別では3つの期間の差を短く載せます。いずれも過去の変化であり、将来の待ち時間予測ではありません。当日の20分保存記録には取得元も含めています。1時間前比の追加によるD1への追加読み取り・書き込みや新しい履歴の保存はありません。
