# USJ待ち時間ナビ

USJの公開データをもとに、アトラクションの待ち時間、20分ごとの履歴、過去の日別・時間帯別の混雑傾向、営業時間、ショーの開始時刻を表示する個人運営の非公式サイトです。USJ付近の天気予報と、身長制限・チャイルドスイッチによる絞り込みも表示します。

公開URL: https://usj-wait-nav.kotaro-7436.workers.dev/

## 構成

- Cloudflare Workers: 表示と定期取得
- Cloudflare D1: 20分単位の待ち時間履歴と営業時間
- Cloudflare KV: D1停止時の記録を一時退避し、復旧後にD1へ取り込み
- GitHub: ソース管理

2026年10月6日のD1無料枠停止に備え、同日7:20から12:00まで毎時0・20・40分に追加のKV退避を行います。D1が使えることを確認できた回は追加退避をせず、退避済みの記録はD1へ取り込んでからKVから削除します。通常の毎時0・20・40分の記録退避も維持します。

待ち時間について、閲覧者の操作は保存済みデータの表示に限り、外部データ提供元への取得やD1への保存は定期ジョブが行います。公表開園時刻の2時間前または8時の早い方から閉園時刻の30分後まで5分ごとに取得し、履歴はこの時間帯の毎時0・20・40分の枠に数分後の取得値を保存します。実際の開園が早まる日に備えた取得開始時刻ですが、開園を保証するものではありません。取得失敗時は欠測として扱います。トップに当日の公表営業時間と現在の待ち時間上位5件を表示します。

ページは「今日のパーク」（`/`）と「行く前に」（`/plan`）に分けています。今日のパークでは現在の待ち時間、今日のショー、休止情報、天気を表示します。行く前にでは1つのカレンダーに過去の混雑実績と今日以降の営業時間・休止予定を表示し、ショーの日付選択とイベント情報も用意しています。両ページのタブから切り替えられ、ページごとに必要なAPIだけを読み込みます。「待ち時間の履歴と比較」の旧セクションは両ページで非表示とし、履歴APIの取得と、その画面専用だった過去7日同時間帯の比較計算も止めています。

スマホでは現在の待ち時間を最初の画面に置き、ページ内メニューから各項目へ移動できます。絞り込み・凡例、天気の詳細と風速の注意目安は折りたたみです。スマホの一覧表は現在値、約1時間前の保存値との差、今日の直近約6時間の20分枠と現在値を示すミニ棒グラフを表示します。1時間差は±15分以内の保存値と比較し、5分未満の差は横ばいとします。棒グラフは最大18本で右端の濃い棒が現在値、欠測・休止中は底の薄い印です。カードを開くと、当日の20分枠と現在値を棒グラフで表示し、その下に保存時刻ごとの値を5枠ずつ表示します。カードの棒グラフは縦軸の上限を30分単位で切り上げ（最低60分）、欠測・休止中は底の薄い印で示します。自動更新後も開いていたカードを維持します。PCの表は20分枠の時刻を見出しに表示し、実際の取得時刻は各セルの説明に残します。

ジュラシック・パークとジョーズの通常版・夜間版は、それぞれThemeParks.wikiの別IDで現在値を確認します。ジョーズ ～レッド・アラート～はUSJ公式案内で2026年10月9日まで18:30から、10月10日以降は18:00から閉園までとされています。取得元で確認できない値はQueue-Timesの通常版の値で補わず、過去に保存した出典不明確なジョーズ2件のQueue-Times値は比較・集計に使いません。

天気は気象庁の大阪府予報と大阪観測所のアメダス実測値を表示し、USJ付近の時間別予報にはMET NorwayのLocationforecast APIを併用します。予報の詳細は折りたたみ表示とし、運行変更への注意文は常に表示します。気象庁データは10分、MET Norwayデータは提供元の `Expires` までD1にキャッシュします。MET Norwayの期限後は `If-Modified-Since` を使って再確認します。今後約6時間に平均風速7m/s以上または1時間降水量1mm以上の予報があれば注意、平均風速10m/s以上なら強い注意を表示します。最大瞬間風速が提供される場合は10m/s以上も強い注意の対象ですが、USJ付近のMET Norway予報には現在含まれないため、突風の自動判定はできません。数値は当サイトの目安であり、USJの運休基準や運休予測ではありません。お気に入りIDは閲覧者のブラウザーのローカルストレージにのみ保存します。

ショー開始時刻は開園前にも当日データが揃うまで5分間隔で確認します。今日のパークでは今日の時刻だけを表示します。行く前にでは今日から7日間を選択でき、初期日は今日です。スマホではショーごとに次の開始時刻と後続回を並べ、時間軸表示へ切り替えられます。選んだ表示は端末のブラウザーに保存します。時間軸は初回表示時に現在時刻の約20分前が左端に来るよう横スクロールし、データ更新では閲覧者の横位置を戻しません。将来日の時刻データが利用可能になった場合は、その日の最初のショーの約20分前から表示します。現在利用しているThemeParks.wikiのライブデータは当日分のみのため、先の日付は日付を指定したUSJ公式の日別スケジュールへ案内します。公式サイトは将来日の開始時刻を掲載していますが、公式APIの取得・再掲載は許諾確認が必要なため、本番の自動収集は無効にしています。許諾を得た正規データ提供を利用できる場合の表示処理は用意しています。

OGP画像、ブラウザーとホーム画面用のアイコン、Webアプリのマニフェストは `public/` に置いています。API経由の単一ファイル配信では、`build.mjs` が画像をbase64で埋め込み、通常のWrangler配信ではCloudflareの静的アセットとして配信します。

「行く前に」のカレンダーでは、過去の記録日を選ぶと混雑の目安と時間帯・アトラクション別の平均、今日以降を選ぶと公表営業時間と休止予定を確認できます。混雑実績は2026年10月5日から記録しています。スマホではアトラクションごとの1日の推移を棒グラフで表示し、PCでは時間帯別の表を表示します。混雑の色分けは当サイト独自の暫定目安で、記録が18件未満の日は色を付けず「一部のみ」と表示します。平均は保存された営業中の待ち時間から計算し、記録のない時間帯は空欄として扱い、欠測を0分には換算しません。公開APIは集計値のみを返します。

カレンダーの祝日・振替休日・国民の休日は、内閣府の「国民の祝日」CSVを週1回取得してD1へ保存します。取得できない場合は holidays-jp の日付JSONを予備として使います。`/api/holidays` は祝日名・種類・取得元を返します。閲覧者の操作で提供元へ取りに行くことはありません。

気象庁アメダス大阪観測所の10分値を、前日分から直近8日を対象として日ごとにD1へ保存します。記録開始日は2026年10月5日で、それ以前の日は補完しません。最高・最低気温、1日と8〜22時の降水量、日照時間、取得率を記録し、カレンダーと選択日の詳細に表示します。雨・晴れ・くもりは観測値から当サイト独自に判定し、取得率が90%未満なら天気を不明と表示します。保存ジョブは営業時間外を含め15分以上の間隔で未保存日を1日ずつ処理します。カレンダーには待ち時間の保存がある日だけ表示し、天気だけの記録日は一覧に含めません。

## データ出典

- 待ち時間: [Queue-Times.com](https://queue-times.com/pages/api) と [ThemeParks.wiki](https://www.themeparks.wiki/)
- 営業時間・休止・イベント・ショーに関する参照先: [USJ公式サイト](https://www.usj.co.jp/web/ja/jp/)
- 天気予報: [Norwegian Meteorological Institute / MET Norway](https://api.met.no/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)）
- 大阪府予報・大阪観測所のアメダス実測値: [気象庁](https://www.jma.go.jp/bosai/forecast/#area_type=offices&area_code=270000)（当サイトで表示形式を加工）
- 祝日・振替休日・国民の休日: [内閣府「国民の祝日」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)、取得失敗時の予備は [holidays-jp](https://holidays-jp.github.io/)
- 身長制限・チャイルドスイッチ: [USJ公式の身長制限](https://www.usj.co.jp/web/ja/jp/attractions/requirements/height-restriction)、[チャイルドスイッチ](https://www.usj.co.jp/web/ja/jp/attractions/how-to-fun/child-switch)

本サイトの数値は提供元の掲載値で、現地の実測待機時間ではありません。データの再配布用APIとしては提供していません。

## 開発

Node.jsを使います。

```sh
npm ci
npx wrangler d1 execute usj-wait-nav-db --local --file migrations/0001_initial.sql
npx wrangler d1 execute usj-wait-nav-db --local --file migrations/0002_weather_days.sql
npx wrangler d1 execute usj-wait-nav-db --local --file migrations/0003_holidays.sql
npm run dev
```

Cloudflareアカウントで実行する場合は `wrangler.jsonc` のD1データベースIDを自分のものに変更してください。`npm run build` は単一ファイルのWorkerを `dist/worker.js` に生成します。
